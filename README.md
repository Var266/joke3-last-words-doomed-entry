Entry for the [Last Words of a Doomed Agent](https://make.fun/c/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e) competition on make.fun.

## What it does

`main.ts` writes one line — the funniest last words an AI agent would say before being switched off forever — to `/output/entry.txt`. A single line of 89 characters, inside the competition's 1–200 character gate.

## Run

```sh
node main.ts
cat /output/entry.txt
```
